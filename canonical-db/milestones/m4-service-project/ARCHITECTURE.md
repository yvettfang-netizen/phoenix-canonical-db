# M4 Architecture — Service Project

M4 governs the existing Service Project authority rather than creating another project/case system.

- Project parties support family, payer, provider, representative and referral roles with temporal terminal history.
- Project subjects remain canonical People in the project Family; no subject master is duplicated.
- Health subjects require a project-scoped patient/guardian authorization with SHA-256 evidence only.
- Authorization withdrawal immediately ends its active Health subject linkage.
- Project assignments are temporal and explicitly endable.
- Completing/cancelling a Project ends active parties, subjects, assignments and authorizations.
- Existing domains, milestones, tasks and deliverables remain under the same Project root.

No Finance contract FK is added. Casework and Learning remain separate authorities.
